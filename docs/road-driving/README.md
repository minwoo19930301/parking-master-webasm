## 추정과 생략

- OSM 도로 중심선은 측량된 차선 주행 궤적이 아닙니다. 양방향 도로14m, 분리 편도9m, 진입로6m는 연습용 폭입니다. 일부 분리 편도에 남은 `lanes=6/8`을 실제 편도 차선 수로 사용하지 않았습니다.
- 반대 차로 연결은 미측정 직선 connector와13m 반경 연습 공간으로 표현합니다. 실제 유턴 반경·정지선·차선 변경 위치로 채점하지 않습니다. 청록색 안내선은 도로 중심선이지 반드시 따라야 할 차선이 아닙니다.
- 도로주행은 평탄한 연습 지면입니다. 시험장 주변의 알려진 건물은 유지하지만 전 경로의 건물 외장·도로 고저·횡단보도·신호주기·보행자는 재현하지 않았습니다. 공개지도 모드의 실제 DEM 배경과 구별합니다.
- 주변 차량36대는 세 차체 비율·여섯 색상·속도를 seed로 무작위 배치합니다. 실제 차량 모델이나 교통량이 아닙니다. 연결된 OSM 구간을 진행하고, 장애물을 만나 감속하며, 화면에서 먼 막다른 구간에서만 재배치합니다. 교차로 신호·보행자·도로교통법 판단을 대체하지 않습니다.
- 현재 위치를 전체 경로에 무조건 최근접 투영하지 않고 도달 가능한 순서 구간만 검사합니다. 출발/도착 및 반복 교차로가 겹쳐도 즉시 완주하지 않습니다. 마지막 접근점에서 정지하면 완주입니다. 출발점은 진입로 기준점이며 실제 시험차 대기선이 아닙니다.

## 재현과 검증

`node tools/build-road-ribbons.mjs`는 GeoJSON에서 폭 추정값을 명시한 C++ 도로 헤더를 생성합니다. 원본 좌표/회전 배열은 `src/dobong/road_routes.h`에 있습니다. `npm test`는 모든 네 경로를1m 간격으로 끝까지 따라 진행 순서·포장면 포함·완주를 검사하고, 지름길 방지·차량 seed·정지·구간 연결·교차 차체 충돌을 검사합니다. 실제 사람의 수동 주행이나 브라우저/GPU/현장 검증을 뜻하지 않습니다.
